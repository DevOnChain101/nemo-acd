# Synthesis UI Kit

This package bundles the current Synthesis visual assets and design references.

## Included
- Transparent logo PNG exports in multiple sizes
- Monochrome logo PNG and SVG variants
- App icon PNG exports plus `.ico`
- Horizontal lockups in PNG and SVG
- Color schema in JSON, CSS, Markdown, and preview PNG
- Landing page and desktop design previews plus HTML source
- Brand boards and extra previews

## Folder guide
- `01-brand/` logo, wordmark, and app icon assets
- `02-design-tokens/` color schema and tokens
- `03-designs/` landing and desktop mockups
- `04-brand-boards/` concept boards
- `05-extras/` preview helpers and backups

## Notes
- The SVG assets are monochrome vector approximations of the selected logo silhouette.
- The primary polished logo remains raster-based in the PNG exports.
